HTML Learning Repository
A collection of HTML practice files created while learning and
practising HTML fundamentals and advanced concepts.
This repository documents my HTML learning journey and gives me a place
to revisit examples as I continue building my web development skills.
Topics Covered
HTML Basics
Located in `HTML_Basics/`
HTML document structure
Headings and paragraphs
Text formatting
Links and images
Line breaks and horizontal rules
Audio and video elements
HTML Advanced
Located in `HTML_Advanced/`
Lists --- ordered, unordered, and nested lists
Tables --- table headings, rows, captions, and sections
Forms --- input fields, radio buttons, checkboxes, dropdowns,
text areas, and other form controls
Repository Structure
``` text
HTML-/
├── HTML_Basics/
│   └── index.html
└── HTML_Advanced/
    ├── form.html
    ├── list.html
    └── table.html
```
How to Run
Clone or download this repository.
Open the project folder on your computer.
Open any `.html` file in your web browser.
No installation or build tools are required.
